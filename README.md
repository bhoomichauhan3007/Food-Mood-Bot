# 🍽️ Food Mood Bot

A simple and interactive **Food Mood Chatbot** that helps users discover food recommendations based on their current mood.

The idea behind this project is simple: your mood can influence what you feel like eating! The chatbot makes food discovery more fun by connecting moods with food suggestions.

## ✨ Features

- 💬 Interactive chatbot interface
- 😊 Mood-based food recommendations
- 🍕 Food suggestions based on user preferences and mood
- 🎨 Simple and user-friendly interface
- 📱 Web-based application

## 🛠️ Tech Stack

- **HTML5** – Structure of the application
- **CSS3** – Styling and user interface
- **JavaScript** – Chatbot functionality and interactions
- **Docker** – Containerization support

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Food-Mood-Bot.git
```

### 2. Navigate to the project directory

```bash
cd Food-Mood-Bot
```

### 3. Run the application

Open `index.html` in your web browser.

You can also use the Live Server extension in VS Code for local development.

## 💡 Project Objective

The objective of Food Mood Bot is to create an engaging chatbot experience that connects users' moods with food recommendations through an interactive web interface.
